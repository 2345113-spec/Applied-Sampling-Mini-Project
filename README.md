Applied Sampling Mini Project
Overview
This project investigates employment confidence among final-year undergraduate students at the University of the Witwatersrand (Wits) and the University of Johannesburg (UJ) using a simulated finite population and a stratified random sampling design.

Files

Data
career_readiness_population.csv: Simulated finite population dataset (N = 10,000).
career_readiness_sample.csv: Realised stratified sample dataset (n = 610).

Code
analysis.R: Reproducible R script containing:
Population generation
Sample size determination
Neyman allocation
Sample selection
Survey estimation
SRSWOR comparison
Monte Carlo simulation
Figure generation

Running the Analysis

Open analysis.R in RStudio.

Set the working directory to the project folder.

Run the script from top to bottom.

The script reproduces all results, tables, and figures used in the project.

Reproducibility
A random seed of 17 is used throughout the analysis to ensure reproducible results.
